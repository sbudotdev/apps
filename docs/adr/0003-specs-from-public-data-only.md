# Gli Spec nascono solo da dati pubblici dell'App Store

Uno **Spec** usa solo ciò che l'App Store mostra a chiunque: classifiche, scheda (descrizione, prezzo, note di versione), screenshot e recensioni. Nessuno strumento del repo decompila, scompatta o estrae asset da un'app altrui, nemmeno da un IPA acquistato. Le **App Sbu** rifanno il comportamento con codice e grafica propri; copiare implementazione, testi o immagini esporrebbe sbu.dev a violazioni di copyright e alla rimozione dall'App Store.

**Eccezione (1/11/2026):** uno Spec può usare anche un audit a scatola nera, fatto da una persona che usa l'app sulla propria copia e la registra. Si annota solo il comportamento: niente testi, grafica o dati copiati, niente analisi del binario o del traffico. Le registrazioni restano fuori dal repo.
